# IaC

Как описывается инфраструктура. Лестница решений.

## Лестница

1. **Одна команда вручную?** Хватит, если поднимается один раз и на одной машине.
2. **Compose?** Один хост, несколько сервисов. Дефолт для проекта.
3. **Ansible или скрипты?** Несколько машин, одинаковые шаги.
4. **Terraform?** Облачные ресурсы, которые нельзя описать compose.

Прыгать через ступень можно только с причиной в одну строку.

## Правила

- версия образа фиксирована, `latest` запрещён
- порты наружу только те, что нужны; остальное в локальную сеть
- volume именованные, путь данных одинаковый в DEV и SERVER
- healthcheck у каждого сервиса, `depends_on` с условием здоровья
- перезапуск не теряет данные

## Идемпотентность

Повторный `up` не меняет состояние. Проверка: `up` дважды подряд, затем сравнение
списка контейнеров и томов.
