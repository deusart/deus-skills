# CI/CD

Пайплайн: что проверяет, что собирает, что деплоит.

## Минимальный пайплайн

1. **Проверки:** линтер, тесты, проверка документации.
2. **Сборка:** образ с фиксированным тегом.
3. **Деплой:** только из основной ветки, только после зелёных проверок.

## Правила

- секреты берутся из хранилища пайплайна, не из файлов репозитория
- деплой идемпотентен: повторный запуск не ломает среду
- откат это тег предыдущего образа, а не правка руками
- миграции базы выполняются отдельным шагом с проверкой
- пайплайн не деплоит с ветки задачи

## Гейты

| Гейт | Блокирует merge | Блокирует деплой |
|------|-----------------|------------------|
| тесты | да | да |
| проверка документации | да | нет |
| ручное подтверждение | нет | для SERVER |
