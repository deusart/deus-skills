# Git

Домен репозиторий. Артефакты: `docs/rules/git.md`, при CI `docs/rules/cicd.md`.

## Origin

- создаётся только после явного согласия; отказ помнится до прямого запроса
- до инициализации опрос по каждой папке первого уровня: секреты, `.env`, кэш,
  артефакты сборки, большие бинарники
- `.gitignore` исключает секреты явно, а не надеется на их отсутствие
- локальная работа не блокируется ожиданием Origin

## Ветки, коммиты, PR

Форматы в `references/naming.md`. В `git.md` фиксируются только решения проекта:
какая ветка основная, есть ли release-ветки, кто мержит, нужен ли ревьюер.

## CI/CD

Обсуждается один раз. Отказ откладывается на потом без повторных вопросов.

Минимум для medium: `tools/check-docs.mjs` на pull request.
Для large: матрица версий, окружения, правила релиза, обязательные статусы проверок.

`cicd.md` отвечает на три вопроса: когда запускается, что проверяет, что блокирует merge.

## Никогда

- force-push в основную ветку
- перезапись истории
- удаление чужих веток
- коммит секретов и ключей
- push тегов без запроса
