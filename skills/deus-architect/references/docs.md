# Docs

Домен документация. Это Obsidian vault в `docs/`.

## Разделы

| Папка | Назначение |
|-------|-----------|
| `docs/rules` | правила репозитория |
| `docs/specs` | спецификации, выполненные уходят в `docs/specs/archive` |
| `docs/concept` | ведёт пользователь, внутрь только точная цитата из чата |
| `docs/tasks` | карточки задач и доска |
| `docs/adr` | решения, large |
| `docs/reviews` | ревью, появляется с первым ревью |

## Паспорт

Единый на medium и large. Первый блок каждого документа. Без паспорта живут
`index.md` и файлы в `docs/concept/`.

```yaml
---
id: SPEC-001
title: "Архитектура решения"
type: spec
status: draft
owner: architect
date: 2026-11-04
related: [ADR-0001, RULE-001]
---
```

| Поле | Обязательное | Значение |
|------|--------------|----------|
| `id` | да | по таблице типов |
| `title` | да | совпадает с H1 |
| `type` | да | spec, adr, rule, review, task, concept |
| `status` | да | из списка своего типа |
| `owner` | да | кто отвечает за содержание |
| `date` | да | ISO, дата последней правки |
| `related` | нет | список существующих `id` |

## Типы и статусы

| type | id | Статусы | Обязательные разделы |
|------|----|---------|----------------------|
| `spec` | `SPEC-001` | draft, approved, implemented | Контекст, Требование, Критерии, Что не входит |
| `adr` | `ADR-0001` | proposed, accepted, superseded | Контекст, Решение, Следствия, Альтернативы |
| `rule` | `RULE-001` | actual, outdated | нет |
| `review` | `REV-001` | new, triaged | Что проверялось, Сводка, Замечания, Что не проверялось |
| `task` | `TASK-001` | backlog, ready, doing, done | нет |
| `concept` | `CONCEPT` | frozen | нет, текст не переписывается |
| `glossary` | `GLOSSARY` | actual | нет |

## Форма

1. Один H1, совпадает с `title`. Второго H1 нет.
2. H2 без пропуска уровней. Новые документы нумеруют разделы: `## 1.`, `## 2.`.
3. Ссылки markdown, идентификаторы в бэктиках. Внутренняя ссылка ведёт на файл.
4. Текст русский, идентификаторы английские.
5. Без длинных тире: дефис или перестроенная фраза.
6. Документ без владельца удаляется.

## Индекс

`docs/index.md`, таблица из двух колонок: путь и назначение одной строкой.

```markdown
| Путь | Назначение |
|------|------------|
| [rules/naming-convention.md](rules/naming-convention.md) | имена файлов, веток, коммитов |
```

Правило: **в индексе нет статуса, типа и даты**. Статус живёт в паспорте, иначе таблица
становится второй копией и разъезжается.

Индекс ведёт агент, проверяет `tools/check-docs.mjs`: каждый документ имеет строку,
каждая строка ведёт в живой файл.

## Доска

`docs/tasks/board.md`, плагин Kanban. Колонки Backlog, Ready, Doing, Done. Файл
начинается с `kanban-plugin: board`, паспорта не имеет и в индекс не входит.

```
---
kanban-plugin: board
---

## Backlog

## Ready

## Doing

## Done
```

Bases и Dataview используются, только если проект уже на них. Плагин не ставится ради
доски.

Доска это удобство для человека. Obsidian видит плагин, агент и CI видят файл, поэтому
проверяется наличие доски, а не её вид.

## Ревью

`docs/reviews/REV-NNN.md` с паспортом и четырьмя разделами плюс:

- таблица: домен | состояние | разрыв | серьёзность (blocker, major, minor)
- "Основа для спеки": от трёх до семи пунктов, каждый станет задачей
- ссылка на предыдущее ревью, если это не первое

Спека на доработку начинается строкой `Источник: docs/reviews/REV-NNN.md`.

## .obsidian

Vault открывается от корня проекта, заметки живут в `docs/`, конфигурация в `.obsidian/`
рядом с `README.md`. Иначе каждый проект назывался бы `docs` в переключателе vault.

`app.json` задаёт `newFileFolderPath: "docs"` и `userIgnoreFilters`: код и служебные
файлы Obsidian не индексирует.

Коммитятся: `app.json`, `appearance.json`, `core-plugins.json`, `community-plugins.json`,
`themes/*`. Не коммитятся: `workspace.json`, `workspace-mobile.json`, кэш и папки
`plugins/*` с кодом плагинов.

`community-plugins.json` фиксирует, какие плагины нужны проекту. Сам плагин ставится в
Obsidian вручную, шаги восстановления пишутся в `docs/rules/tools.md`.

Набор по умолчанию: `obsidian-kanban`, `dataview`, `obsidian-minimal-settings`, тема
Minimal. В `appearance.json` это `"theme": "obsidian"` плюс `"cssTheme": "Minimal"`.
Тема лежит в репозитории, поэтому вид восстанавливается сразу, а плагины ставятся один
раз вручную.
