# SQL

Запросы и модели на SQL. Диалект проекта: ClickHouse, версия из docker-образа.

## Диалект

- синтаксис ClickHouse, перенос с postgres запрещён
- функция или тип проверяются по версии из образа, а не по памяти
- `PREWHERE`, `FINAL`, `ARRAY JOIN` это инструменты, а не украшения: каждое применение
  объясняется одной строкой
- служебные таблицы `system.*` для диагностики, не для витрин

## Форма запроса

- CTE вместо вложенных подзапросов, один шаг одна CTE, имя по смыслу
- список колонок явный; `SELECT *` только в исследовательском запросе
- ключевые слова заглавными, один шаг на строку
- алиасы короткие, `s`, `o`, `m` по первой букве таблицы, не `a1`, `t2`
- условие это фильтр, а не комментарий: `-- только активные` не заменяет `WHERE`

## Откуда читать

| Задача | Слой |
|--------|------|
| отчёт и витрина | marts |
| разбор и отладка | staging |
| проверка источника | raw |

Таблица читается в одном слое. Импорт из raw в marts напрямую это ошибка слоя.

## Производительность

- фильтр по партиции первым
- тяжёлый фильтр в `PREWHERE`
- ключ сортировки не оборачивается в функцию: `toDate(ts) = ...` отключает индекс
- `LIMIT` на исследовании, иначе запрос читает весь объём
- тяжёлый join проверяется `EXPLAIN` до запуска на боевых данных

## Корректность

- зерно фиксируется до join, иначе строки размножаются
- NULL сравнивается через `IS NULL`, не через `= NULL`
- время хранится в UTC, конвертация только на чтении
- деньги и счётчики в decimal, не в float
- фильтр по правой таблице в `WHERE` превращает `LEFT JOIN` в `INNER JOIN`; для
  сохранения левой стороны условие уходит в `ON`

## Ревью запроса

- [ ] зерно результата названо и не размножается join
- [ ] фильтр по партиции есть
- [ ] нет `SELECT *` в модели
- [ ] NULL и типы проверены
- [ ] чтение из правильного слоя
- [ ] тяжёлый запрос проверен `EXPLAIN`
