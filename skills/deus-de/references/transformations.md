# Transformations

dbt: слои, материализация, лестница решений.

## Лестница

Бери первый вариант, который работает:

1. **Нужна ли модель?** Если поле можно посчитать на чтении без потери скорости, модель
   не создаётся.
2. **Есть в проекте?** Макрос, тест или модель уже есть. Второй способ не вводится.
3. **Стандарт dbt?** Встроенный тест, инкремент, snapshot вместо самописного решения.
4. **Свой макрос** только если без него модель становится нечитаемой.

## Слои

| Слой | Что делает | Материализация |
|------|------------|----------------|
| staging | переименование, типы, дедуп | view |
| intermediate | соединения и расчёты | ephemeral или view |
| marts | витрина для чтения | table или incremental |

Модель не читает raw напрямую из marts и не прыгает через слой.

## Инкремент

Инкрементальная модель обязана иметь:

- уникальный ключ и стратегию (merge или delete+insert)
- окно обновления, переживающее опоздавшие данные
- тест на дубли после прогона

## Тесты

Минимум на модель: уникальность ключа, not null на ключевых полях, accepted values для
перечислений, relationships к родительской таблице.
