# Quality

Проверки данных: тесты, свежесть, объёмы, алерты.

## Четыре проверки на слой

1. **Ключ.** Уникален, не пуст.
2. **Полнота.** Число строк за период в ожидаемом диапазоне.
3. **Свежесть.** Максимальная дата не старше расписания плюс допуск.
4. **Согласованность.** Сумма по витрине равна сумме по источнику за тот же период.

## Где живёт проверка

- dbt-тесты: структура, ключи, значения
- сенсоры и SQL-проверки: свежесть и объёмы
- алерт: кто получает, что делает, когда молчит

Проверка без получателя алерта считается отсутствующей.

## Что не делаем

- проверку, которая всегда зелёная
- порог, выставленный после первого прогона и не пересмотренный
- «починим данные потом» без задачи на доску
