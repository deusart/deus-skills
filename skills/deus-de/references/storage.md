# Storage

Схема хранилища: базы, таблицы, движки, партиции, миграции.

## Обязательный минимум таблицы

| Что | Зачем |
|-----|-------|
| База и имя | по `docs/rules/naming-convention.md` |
| Движок | MergeTree для фактов, отдельный выбор для словарей |
| Ключ сортировки | по нему идут запросы |
| Партиции | по дате, если объём растёт |
| TTL | сколько живёт строка |
| Зерно | одна строка это что |

Нет строки в этой таблице, нет таблицы.

## Миграции

- имя: `NNN_<что>` в `docker/clickhouse/init` или `migrations`
- миграция только добавляет; удаление колонки отдельным шагом
- у каждой миграции есть откат или явная запись, что откат невозможен
- переименование это новая колонка плюс перенос, а не `RENAME` на живой таблице

## Слои

- `raw`: как пришло от источника
- `staging`: типы приведены, дубли убраны, имена человеческие
- `marts`: готово к чтению, соединения сделаны

Таблица живёт ровно в одном слое.
