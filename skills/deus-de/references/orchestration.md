# Orchestration

Airflow: DAG, расписание, retries, backfill.

## Один DAG на слой

- DAG не содержит бизнес-логики, только порядок вызовов
- зависимость между слоями задаётся данными (dataset или сенсор), а не `sleep`
- расписание пишется в `docs/rules` и в коде одинаково

## Обязательные параметры

| Параметр | Значение |
|----------|----------|
| `retries` | не меньше 2 |
| `retry_delay` | с обоснованием |
| `execution_timeout` | есть всегда |
| `catchup` | осознанно, по умолчанию false |
| `concurrency` | ограничен источником или хранилищем |

## Идемпотентность

Запуск за тот же интервал не меняет результат. Проверка: rerun DAG за прошлую дату и
сравнение числа строк.

## Backfill

Описан в DAG или рядом: какой интервал, чем ограничен, что делать с опоздавшими
данными, кто запускает.
